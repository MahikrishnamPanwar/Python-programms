💻 How to Run the Programs

Follow these steps to run the programs on your computer.

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the project

Open PyCharm.
Select Open.
Choose the cloned project folder.

Step 3: Set up the Python interpreter

Make sure Python is installed and the correct Python interpreter is configured in PyCharm.

Step 4: Run a program

Open any .py file.
Right-click inside the file.
Select Run 'filename'.

You can also run a program from the terminal:

python filename.py

Replace filename.py with the name of the Python file you want to execute.
